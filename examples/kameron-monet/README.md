# Example run: @KameronMonet, 22 Nov 2026

- 100 videos indexed, about 800 lexicon terms.
- News window 16 to 22 Nov 2026. Ten stories shortlisted, 59 clips.
- Thirty motion options: three per story, each in a different palette.

Caveats on this run: clip cards were not built (clips were found by transcript search and read in context), scores were set in the same pass that found the pairs, and the AI ads lawsuit story has a single source.

To watch the finished pairings, open `runs/2026-11-22/clips/motion-with-clips.html` in a browser. The ten cut clips sit beside it. Each clip plays under its three motion graphics, with captions and the end pop-up.
